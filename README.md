# Yulechka Daily Card

## Настройки генерации

Поэтическая часть (ласковая рифма и двустишие) генерируется отдельно от оформления и арта.
Провайдер выбирается переменной GitHub Actions `VERSE_PROVIDER`:

- `gemini` — только Gemini (значение по умолчанию);
- `openrouter` — только Claude через OpenRouter;
- `auto` — сначала Claude через OpenRouter, при неудаче Gemini.

Переменную можно задать в репозитории: **Settings → Secrets and variables → Actions → Variables**.

Генератор передаёт поэтической модели московскую дату, текущее время года и подходящий
календарный повод. Упоминать календарь каждый день не требуется, но сезонные ссылки строго
проверяются: стих с неправильным временем года автоматически отклоняется и генерируется заново.
На значимые даты — например, Новый год, 14 февраля, 8 марта, 1 сентября или День семьи —
модель может естественно использовать повод, если он подходит двустишию.

### Режим арта

Переменная `ART_MODE`:

- `auto` — чередовать `scene`, `svg`, `image` и `video` (по умолчанию);
- `svg` — генеративный SVG;
- `scene` — живая canvas-сцена;
- `image` — вертикальная AI-иллюстрация с адаптивным кадрированием и анимированными слоями.
- `video` — та же AI-иллюстрация, деликатно оживлённая в бесшовный четырёхсекундный видеофон.

Для `image` используется OpenRouter Images API и модель из переменной `IMAGE_MODEL`
(`google/gemini-3.1-flash-image` по умолчанию). Нужен секрет `OPENROUTER_API_KEY`.
Если генерация изображения недоступна,
открытка остаётся рабочей и показывает градиент с живым слоем.

Для `video` исходная иллюстрация публикуется отдельным промежуточным коммитом, после чего
OpenRouter Video API создаёт 4-секундный MP4 без звука. По умолчанию используется
`bytedance/seedance-1-5-pro`; модель меняется переменной `VIDEO_MODEL`. Первый и последний
кадры закреплены на исходной иллюстрации, а промпт разрешает только контекстные микроэффекты:
блики, блёстки, переливы и едва заметное движение деталей. При ошибке видео сайт автоматически
остаётся на статичном изображении. После генерации последние 0,45 секунды мягко сводятся к
началу ролика через FFmpeg, поэтому петля остаётся бесшовной даже при небольшом дрейфе модели.
